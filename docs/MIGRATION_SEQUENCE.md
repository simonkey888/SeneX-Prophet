# SENEX migration sequence

`governance/migration_map.json` is a proposal only. No file movement is performed in this mission. The order is WAVE_0 through WAVE_9: contract/inventory; evidence/replay; adapters/ingestion; features/regimes; research/strategy separation; decision/risk; paper execution/portfolio; observability/security/API; legacy retirement; live execution remains quarantined. Every future migration requires separate AUD authorization, tests, and rollback.
