# SENEX target architecture

The executable source is `governance/target_architecture.yaml`. It defines 24 domains and denies wallet, real-order, live-capital, and production authority everywhere. `EXECUTION_LIVE_QUARANTINED` is deliberately unreachable.

The paper path is: public GET adapters → immutable hashed evidence → existing deterministic H011 decision semantics → fail-closed paper risk → simulated broker → append-only virtual portfolio → hashed reports.

No component using AI, research, or learning may write authoritative raw evidence, production state, wallets, orders, or capital.
